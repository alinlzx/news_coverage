## Purpose

This repository offers code to replicate analyses in my news coverage project. 

## How to Run the Code

### Data

Raw files pulled from ACLED and NYT API can be found under `data/raw `. 

### Code

Code should be run in the following order: 

1. `code/build`, in the order in which the files are numbered.
2. `code/analysis`, in the order in which the files are numbered.

### Exhibits

1. Maps, dual bar plots, and country-level point plots (exhibits 1-5) are generated by 01 analysis file.
2. Event-level point plots and time series (exhibits 6-7) are generated by 02 analysis file.
3. Contingency tier plots (exhibit 8) is generated by 01a analysis file.
4. Actor bar plots (exhibit 9) is generated by 07 analysis file.
